# Разбор задания 2

Готовый самодостаточный файл — `public/games/ege-2-poshagovo.html`. Исходники — `games-src/ege-2-poshagovo/` (`engine.mjs`, `ui.js`, `template.html`, `build.mjs`), сборка — `node games-src/ege-2-poshagovo/build.mjs`. Обложка — `public/posts/ege-2-poshagovo.jpg` (снимок шага «Программа по строкам», `npm run posters ege-2-poshagovo`).

Формат — разбор (`type: guide`) для показа учителем и самостоятельной работы: семь шагов, шапка с выбором шага, план со ссылками, тёмная тема, размер текста 18–32 px, полноэкранный режим, клавиатура (← → шаги, Page Up / Down трасса, Esc стоп).

1. Условие и план: выражение, фрагмент из трёх различных строк с пустыми клетками, числа считаются из данных.
2. Логика на Python: соответствия операций с живым пересчётом при выборе a и b; импликация двумя способами (`not a or b`, `a <= b`); приоритет сравнений раньше `and`/`or`.
3. Программа по строкам: четыре вложенных цикла, клик по строке — пояснение; трасса с панелью переменных, автопоказом, пропуском к строке вывода; упомянута версия с `itertools.product`.
4. Сопоставление столбцов: выбор переменных для столбцов фрагмента, проверка с объяснением противоречия конкретной строкой, подсказки из данных, показ ответа.
5. Проверь себя: пять вопросов, каждый вариант объяснён; счёт с первой попытки.
6. Вся программа: копирование и скачивание .py; продвинутый шаг — полностью автоматическое решение перебором перестановок и заполнений пропусков.
7. Авторешение по строкам: комментарий у каждой строки автоматической программы (`advancedLines`); трасса перебора (`advancedTrace`) показывает перестановку p, заполнение a, фрагмент с подставленными пропусками и причину отбраковки/совпадения; «К ответу» перескакивает к единственному верному кандидату.

Данные собственные: генератор (`makeTask`, детерминированный seed, по умолчанию 20261112) выбирает одно из 10 своих выражений, переименовывает переменные, берёт 3 строки решений и 2–4 пропуска; единственность ответа проверяется полным перебором (24 перестановки × 2^k заполнений). Кнопка «Новая задача» меняет seed. Задания демоверсий и открытого банка ФИПИ не используются.

В продвинутой программе имена переменных заданы явно: приём `f.__code__.co_varnames` из чужих разборов ломается на Python 3.12 (генераторы списков попадают в общий код функции), об этом есть предупреждение на странице.

Проверки:
- `node games-src/ege-2-poshagovo/check-engine.mjs` — 30 seed сверяются с `oracle.py`: таблицы истинности, вывод главной программы и версии с product (запускаются на Python), автоматическое решение, единственный ответ, трасса, квиз, проверка сопоставления; у каждой строки авторешения есть комментарий, трасса авторешения печатает единственный ответ.
- `node games-src/ege-2-poshagovo/check-page.mjs` — jsdom: страница открывается без ошибок, трасса доходит до конца, неверный порядок столбцов объясняется, верный проходит, квиз засчитывает ответы, программы совпадают с движком, слайд авторешения листается до ответа, новая задача и тема работают.
- `npm run validate` — сборка сайта и общие тесты.
