Часть 2 · задача

Минимальное R, большее 150

Самостоятельная учебная задача с преобразованием двоичной записи. Сначала прочитай условие, потом проследи алгоритм на нескольких N.

Условие

На вход алгоритма подаётся натуральное число N. Алгоритм строит по нему новое число R так:

  1. Строится двоичная запись числа N.
  2. Запись обрабатывается по правилу:
    а) если N делится на 3, справа дописываются две последние цифры двоичной записи;
    б) если N на 3 не делится, остаток от деления N на 3 умножается на 5, переводится в двоичную систему и дописывается справа.
  3. Полученная запись является двоичной записью числа R.

Например, 12 = 1100₂ → 110000₂ = 48. Для 7 = 111₂: остаток 1, 1 · 5 = 5 = 101₂ → 111101₂ = 61.

Укажите минимальное число R, большее 150, которое может получиться в результате работы алгоритма. Ответ запишите в десятичной системе.

Спрашивают про минимальное R, а не про минимальное N. Это два разных вопроса с разными ответами.

Часть 3 · программа

Одна строка — одно действие

Нажимай на строки по очереди. Справа видно, что делает строка и какие значения у переменных в этот момент. Строки ветви, которая не выполняется, отмечены серым.

Часть 4 · перед перебором

Сколько N нужно перебрать?

Шаг 1. R всегда хотя бы в 4 раза больше N

В обеих ветвях к записи N дописываются цифры справа: две цифры, или 101 (три), или 1010 (четыре).

Дописать справа одну двоичную цифру — значит умножить число на 2 и что-то прибавить. Две цифры — умножить хотя бы на 4. Поэтому всегда R ≥ 4 · N.

11₁₀ = 1011₂ → 10111010₂ = 186 ≥ 4 · 11 = 44

Шаг 2. Отбрасываем лишние N

Уже при N = 11 получается R = 186 > 150. Значит, ответ не больше 186.

Если N ≥ 47, то R ≥ 4 · 47 = 188 > 186. Такие N ответ не улучшат. Достаточно проверить N от 1 до 46:

for n in range(1, 47):

На экзамене проще взять с запасом: range(1, 1000). Компьютер переберёт тысячу чисел мгновенно, а ответ не изменится, потому что большие N дают только большие R.

Часть 6 · решение

Вся программа

Решение целиком в одном цикле. Подходящие r сохраняем в a, а после цикла выводим min(a). Никакой функции для всей задачи не требуется.

Как проверить отдельный пример
n = 12
b = bin(n)[2:]
if n % 3 == 0:
    b += b[-2:]
else:
    b += bin((n % 3) * 5)[2:]
r = int(b, 2)
print(r)

Для n = 12 получится 48. Затем поменяй n на 7: получится 61. Для проверки одного входа цикл не нужен.

Как узнать не только R, но и N
a = []
for n in range(1, 1000):
    b = bin(n)[2:]
    if n % 3 == 0:
        b += b[-2:]
    else:
        b += bin((n % 3) * 5)[2:]
    r = int(b, 2)
    if r > 150:
        a.append((r, n))
print(min(a))

В a сохраняем пары (r, n). Сначала сравниваются r, затем n. Получится (157, 19).

Проверка без программы, арифметикой

Дописать справа k двоичных цифр со значением t — то же, что n * 2**k + t.

n % 3 == 0  →  R = n * 4 + n % 4
n % 3 == 1  →  R = n * 8 + 5
n % 3 == 2  →  R = n * 16 + 10

Для N = 19: остаток 1, R = 19 · 8 + 5 = 157. Для N = 18: R = 18 · 4 + 2 = 74 — мало. Для N = 20: R = 20 · 16 + 10 = 330 — больше.

Часть 7 · тот же алгоритм

Другой вопрос — другие последние строки

Блок от b = bin(n)[2:] до r = int(b, 2) не меняется. Меняются отбор, добавляемое значение и последняя строка. Выбери тип вопроса и порог: код и ответ пересчитаются.

Часть 8 · шаг дальше

Та же задача в троичной системе

Для троичной записи вынесем в функцию только перевод числа. Само решение останется обычным циклом со списком a.

Меняем систему счисления

Строится троичная запись N. Если N делится на 3, дописываются две последние троичные цифры. Иначе остаток, умноженный на 5, переводится в троичную систему и дописывается справа. Найти минимальное R, большее 150.

В коде меняются три места: bin(n)[2:] заменяем на f(n, 3), bin((n % 3) * 5)[2:] — на f((n % 3) * 5, 3), а int(b, 2) — на int(b, 3).

Примеры: 6 = 20₃ → 2020₃ = 60. 4 = 11₃, остаток 1, 5 = 12₃ → 1112₃ = 41.

def f(x, base):
    if x == 0:
        return '0'
    s = ''
    while x > 0:
        s += str(x % base)
        x //= base
    return s[::-1]

a = []
for n in range(1, 1000):
    b = f(n, 3)
    if n % 3 == 0:
        b += b[-2:]
    else:
        b += f((n % 3) * 5, 3)
    r = int(b, 3)
    if r > 150:
        a.append(r)
print(min(a))

Справочник

Редкие приёмы

Встречаются в старых вариантах и авторских задачах. Возвращайся сюда, когда условие требует.

Восьмеричная и шестнадцатеричная запись
oct(n)[2:]
hex(n)[2:]
f'{n:X}'
int('AF', 16)

hex даёт маленькие буквы a–f, f'{n:X}' — большие A–F. Для систем больше 10 в f бери цифру из строки-алфавита: '0123456789ABCDEFGHIJ'[x % base].

Фиксированная разрядность: «восьмибитная запись»
s = f'{n:08b}'
s = bin(n)[2:].zfill(8)

Ноль спереди добавляется, только если запись короче 8 цифр. Обрезать длинную запись эти команды не умеют.

Старый тип: цифры десятичного числа
a, b, c, d = map(int, str(n))
sums = sorted([a + b, b + c, c + d])
result = int(''.join(map(str, sums[1:])))

Сортируй числа до перевода в строки: число 12 больше 3, а строка '12' меньше строки '3'. Перебор четырёхзначных: range(1000, 10000).

Двоично-десятичная запись: каждая цифра — 4 бита
s = ''.join(f'{int(d):04b}' for d in str(n))

Для 95 получится '10010101': 9 → 1001, 5 → 0101.

Побитовые операции
n.bit_count()
n << 2
n >> 2

n.bit_count() — число единиц, то же что bin(n).count('1'). n << 2 дописывает два нуля справа (умножение на 4), n >> 2 удаляет две последние цифры.
