    Верю — не верю
    
    
    

    
    
      
    Работа длится 10 минут. Ты читаешь программу на Python и решаешь, верно ли утверждение о том, что она выведет. Темы идут по кругу — линейные программы, ветвление, while, for — и с каждым кругом программы сложнее.
    
      
      
    За что даются баллы
    
      
    
      
    Оценка
    
      
    
      
    Правила
    
      
      
    
      

    
      
      
      Прочитай программу и выполни её в уме. Потом реши: верить утверждению или нет. После ответа программа выполнится по шагам — видно каждую строку, переменные и вывод.

      Сложность

      Справка
      
    
      Трассировка
      
    
      Выполняй программу строка за строкой и записывай значения переменных после каждой строки. Переменная хранит только последнее присвоенное значение.
      
    
      Арифметика
      
    
      17 / 5   → 3.4   обычное деление, результат дробный
17 // 5  → 3     целая часть от деления
17 % 5   → 2     остаток от деления
2 ** 3   → 8     возведение в степень
      
    
      Порядок действий: сначала **, потом * / // %, потом + и -. Скобки меняют порядок. Цифры числа: n % 10 — последняя, n // 10 — число без последней цифры.
      
    
      Ветвление
      
    
      if a > 20:
    print("A")
elif a > 5:
    print("B")
else:
    print("C")
      
    
      Выполняется только первая ветка, где условие истинно; остальные уже не проверяются. Несколько отдельных if подряд проверяются все.
      
    
      > и < — строгое сравнение (5 > 5 — False), >= и <= — нестрогое (5 >= 5 — True), == — равно, != — не равно.
      
       and истинно, только если истинны обе части; or — если истинна хотя бы одна; not меняет значение на противоположное.
      
    
      Циклы
      
    
      i = 1                    for i in range(1, 5):
while i <= 3:                print(i)   # 1 2 3 4
    print(i)   # 1 2 3
    i = i + 1
      
    
      while проверяет условие перед каждым повтором и заканчивается, когда условие ложно.
      
       range(a, b) — числа от a до b − 1 (правая граница не входит), range(n) — от 0 до n − 1, range(a, b, k) — с шагом k.
      
       Что внутри цикла, решают отступы: строка с отступом выполняется на каждом повторе, без отступа — один раз после цикла.
      
    
      Обмен значений
      
    
      После a = b старое значение a потеряно. Обменять можно через третью переменную (c = a, a = b, b = c) или записью a, b = b, a: в ней правая часть вычисляется целиком до присваивания.
