# Задание 8 ЕГЭ: Python по шагам

Материал для учителя: три блока, 34 демонстрации, шесть авторских задач. Код и его работа рядом, отдельное окно объяснения, изменяемые примеры, скрытие проверок и итогов, скачивание программ. Разделы постоянно расположены на одной странице. Текст по умолчанию 24 px, регулируется от 22 до 32 px; доступны клавиатура, светлая/тёмная тема и полноэкранный режим.

Пункт 7 первоначального плана (мини-задачи и отдельный проверочный тренажёр) отменён автором. Шесть разборов из этапов 4–6 сохранены.

Адрес карточки: https://infoshag.ru/item/ege-8-poshagovo/

Запуск: https://infoshag.ru/igra/ege-8-poshagovo/

## Файлы и сборка

- `public/games/ege-8-poshagovo.html` — автономный материал без внешних ресурсов.
- `public/downloads/ege-8-poshagovo.zip` — HTML и памятка учителю.
- `games-src/ege-8/` — вычислительные модели, содержание и интерфейс.
- `design/site/ege-8-poshagovo.svg` — исходник типографической обложки; `public/posts/ege-8-poshagovo.jpg` — 1280×800, 16:10.
- `scripts/package-ege8.mjs` — повторная сборка HTML, обложки и ZIP. Нужны установленные зависимости сайта и Python 3; путь к Python задаётся переменной `PYTHON`.

Из корня репозитория: `node scripts/package-ege8.mjs`.

Только HTML: `node games-src/ege-8/build.mjs public/games/ege-8-poshagovo.html`.

Памятка находится рядом с этим README и включается в ZIP.

## Проверка

`node games-src/ege-8/check-engine.mjs` — 108 наборов первого блока со сверкой и исполнением показанного Python.

`node games-src/ege-8/check-course.mjs` — ещё 70 программ новых методов и задач, включая альтернативные решения. Проверяются обратимость нумерации и совпадение подсчёта формулой, рекурсией, отсечениями, выбором позиций и динамикой. Обе команды используют `PYTHON` или системный `python`.

Ответы задач: 1 — 40; 2 — 10; 3 — номера 22 и 180; 4 — ЛКМЛ и 229; 5 — 144; 6 — 162 при длине 5 и 5854354056 при длине 18. Большой полный перебор не запускается. Числа вычисляются моделями, а не подставляются в интерфейс.

В Chrome проверены все методы и шаги задач при ширинах 1366, 1024 и 390 px, отдельное окно объяснения, скрытие ответов, изменение параметров, ошибки ввода, клавиатура и скачивание исполняемой программы. Самостоятельный HTML совпадает с версией, прошедшей эти проверки.

Общая проверка сайта: `npm run validate`.
