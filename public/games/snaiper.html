Правила

    Справка

    Как решать задание 3

    1. Сними НЕ. НЕ меняет и направление знака, и строгость: 
      НЕ (X < 5)  →  X ≥ 5        НЕ (X ≤ 5)  →  X > 5
НЕ (X > 5)  →  X ≤ 5        НЕ (X ≥ 5)  →  X < 5
НЕ (X чётное)  →  X нечётное
    2. Отметь каждую часть на числовой прямой.
    3. Сложи части. И — истинны обе части: берём общую часть полос. ИЛИ — истинна хотя бы одна: берём всё, что закрашено.
    4. Если спрашивают «ложно» — нужны числа, которые не попали в итоговую полосу.
    5. Учти, какие числа разрешены: натуральные — 1, 2, 3, …; двузначные — от 10 до 99; трёхзначные — от 100 до 999.
    6. Наименьшее — самое левое подходящее число, наибольшее — самое правое.
    7. Проверь подстановкой ответ и соседнее с ним число.

    Пример

    Наименьшее целое X, для которого истинно НЕ (X < 5) И (X < 9).

    НЕ (X < 5)  →  X ≥ 5
X ≥ 5 И X < 9  →  5, 6, 7, 8
наименьшее: 5
проверка X = 5: НЕ (5 < 5) = НЕ (ложь) = истина; 5 < 9 — истина; истина И истина = истина
проверка X = 4: НЕ (4 < 5) = НЕ (истина) = ложь — не подходит

    Порядок действий в высказывании: сначала НЕ, потом И, потом ИЛИ. Скобки меняют порядок.

    Строго и нестрого: X < 5 — число 5 не подходит; X ≤ 5 — подходит.
