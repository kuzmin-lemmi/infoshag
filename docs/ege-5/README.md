# Разбор задания 5

Содержание блоков Python и дополнительного справочника — `GUIDE-DRAFT.md`.
Шаблон интерфейса и интерактивные примеры — `games-src/ege-5/template.html`.

После изменения конспекта или шаблона выполнить из корня репозитория:

```sh
node scripts/build-ege5-guide.mjs
npm run validate
```

Результат — самодостаточный `public/games/ege-5-poshagovo.html`.
Библиотеки при открытии страницы не требуются; Google Fonts имеют системные замены.

Проверено перед публикацией: 12 учебных блоков и ответы, 997 входных значений
в сравнении с Python, обе ветви построчного разбора, полный перебор и пять порогов.
У исходной функции отдельно проверялось совпадение с арифметической реализацией
для N от 4 до 100000. На странице проверены ширина 320 пикселей и обе темы.

Основной ответ — R = 234 при N = 58. Первое подходящее N = 19 даёт R = 335.
Граница перебора — N ≤ 240: есть подходящий результат 240, и во всех ветвях R ≥ N.
