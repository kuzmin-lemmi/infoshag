## Банк идей

Приоритет — темы, которые сейчас проходят в школе, и задания ОГЭ.

**7 класс**
- Кодирование графики и звука: пиксели, глубина цвета, объём изображения
- Перфолента / кодирование: «пробей» команду отверстиями, машина выполняет
- Устройство компьютера: собери компьютер из деталей, назначение устройств

**8 класс — системы счисления и логика**
- Двоичный тетрис: падает десятичное число, переключи биты до приземления
- Обменник: «валютный обмен» чисел между системами на время
- Сломанный калькулятор: найди неверный разряд в готовом примере
- Собери схему: логические элементы И/ИЛИ/НЕ, лампочка загорается при заданных условиях
- Детектив: логические задачи «каждый сказал одну правду и одну ложь»

**8 класс — алгоритмы и программирование**
- Кухня: расставь шаги рецепта, потом ветвление и цикл
- Отследи переменную: значение после цепочки присваиваний (ловушка a := b; b := a)
- Исполнитель Удвоитель: «прибавь 1 / умножь на 2» за минимум шагов (ОГЭ)
- Найди баг: клик по строке с ошибкой
- ~~Что выведет программа~~ — сделано как «Верю — не верю» (2026-10-17)
- Пазл из кода: собрать строки в правильном порядке с отступами

**9 класс / ОГЭ**
- Графы: «Сколько путей из A в G» — пошаговая анимация подсчёта путей (задание ОГЭ про графы)
- Таблицы расстояний: кратчайший путь
- Файловая система: полный путь к файлу, маски имён
