# Запись роликов игр в OBS

Пошаговая инструкция: как с нуля поставить OBS на новом компьютере и записать ролик геймплея
для ВК и сайта. Проверена 2026-10-19 на Windows 11, OBS Studio 32.2.2.
Зачем ролики и какими они должны быть — `docs/VK.md`, раздел «Клипы».

## 1. Установка

1. Скачай установщик только с официального сайта: https://obsproject.com/ru → кнопка **Windows**
   (файл вида `OBS-Studio-32.x-Windows-x64-Installer.exe`, около 150 МБ).
2. Запусти, подтверди «Разрешить внесение изменений», везде **Next**, папку не менять, **Install → Finish**.
3. При первом запуске появится «Мастер автоматической настройки»: выбери
   **«Оптимизировать только для записи, трансляции не нужны»** → разрешение **1920×1080**, частота **30** →
   **Применить настройки**. Если мастер не появился — настройки ниже сделаем вручную.

## 2. Настройки (кнопка «Настройки» в блоке «Управление»)

**Вывод** (режим вывода — «Простой»), раздел «Запись»:

| Параметр | Значение |
|---|---|
| Путь записи | любая папка, например `D:/Инфошаг` |
| Генерировать имя файла без пробела | включить |
| Качество записи | Высокое качество, средний размер файла |
| Формат записи | Фрагментированный MP4 (.mp4) (или MPEG-4) |
| Кодировщик видео | Программный (x264) |

**Видео:**

| Параметр | Значение |
|---|---|
| Разрешение предпросмотра (холст) | 1920x1080 |
| Разрешение выхода (масштабное) | 1280x720 |
| Общие значения частоты кадров | 30 (по умолчанию 60 — файл выйдет вдвое тяжелее без пользы) |

**Аудио:** «Звук рабочего стола» и все «Микрофон/дополнительный звук» — **Отключено**.
Звук в роликах не нужен, и в запись не попадут уведомления.

**Горячие клавиши:** «Начать запись» — **F9**, «Остановить запись» — **F10**.

Применить → ОК. Итог: файл 1280×720, 30 кадров/с, около 1–2 МБ на ролик в полминуты.

## 3. Источник: окно с игрой

1. Открой Chrome **отдельным окном** (Ctrl+N), перейди на страницу игры, например
   `https://infoshag.ru/igra/ohota-za-rasshireniyami/`, нажми **F11** (полноэкранный режим: без вкладок и адресной строки).
2. Alt+Tab в OBS. В блоке **«Источники»** нажми **+ → «Захват окна»**, назови «Игра».
3. В свойствах: **Окно** — строка `[chrome.exe]` с названием игры; **Метод захвата** — «Windows 10 (1903 и выше)»
   (со старым методом Chrome даёт чёрный экран); «Захватывать курсор» — оставить.
4. Если картинка не заполняет поле: ПКМ по источнику → **Преобразовать → Растянуть по экрану** (Ctrl+F).
5. Готово, когда в превью OBS видна игра на всё поле без рамок браузера.

Для другой игры — в свойствах источника выбрать другое окно (или открыть новую игру в том же окне Chrome).

## 4. Запись

1. Alt+Tab в Chrome, выбери настройки игры (для «Охоты»: миссии по очереди, 60 с, акула — да).
2. **F9** — запись пошла (таймер виден только в OBS). Играй по сценарию из `docs/VK.md` (таблица «Сценарии для готовых игр»):
   первые 2 секунды — самое зрелищное, мышью двигай спокойно, без рывков.
3. **F10** — стоп. Файл появится в папке записи (`2026-10-19_13-46-58.mp4`).
4. Сделай 2–3 дубля: первый почти всегда выходит неловким.

## 5. Обрезка и публикация

- Нужно 15–30 секунд, и ролик начинается уже с процесса игры. Обрезать: ПКМ по файлу → **Открыть с помощью → Clipchamp**
  (встроен в Windows 11) → подрезать края → экспорт 720p.
- **ВК:** «Создать → Запись» → текст поста из `docs/VK-POSTS.md` → значок «Видео» → загрузить файл → опубликовать от имени группы
  → первым комментарием вопрос из `docs/VK-POSTS.md`.
- **Клипы ВК** требуют вертикальный формат 9:16: сузь окно браузера до вертикального прямоугольника, игра перестроится.
- **Сайт** (поле `video` в карточке, `public/posts/<slug>.mp4`): ролик ~720p, 2–4 МБ, без звука
  (`docs/ROADMAP.md`, этап 2, скрипт подготовки роликов).

## 6. Если что-то не так

- **Чёрный экран в превью** — метод захвата «Windows 10 (1903 и выше)»; закрыть и снова выбрать окно Chrome.
- **Окна Chrome нет в списке** — открыть его отдельным окном (Ctrl+N) и не сворачивать.
- **Файл тяжёлый** — проверить частоту 30 и выход 1280x720.
- **В кадре лишнее** — F11 в браузере; закрыть уведомления и мессенджеры перед записью.
