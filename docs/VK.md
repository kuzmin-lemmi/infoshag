# Группа во ВКонтакте

Роль группы — витрина и рост аудитории (см. `docs/STRATEGY.md`). Игры в ВК не запускаются:
каждый пост ведёт на страницу игры на сайте.

**Сообщество:** https://vk.ru/infoshag

## Оформление

- **Название** — то же, что у сайта и домена (решение этапа 0).
- **Описание** (2–3 строки): «Бесплатные игры и тренажёры для уроков информатики по учебнику Босовой
  и подготовки к ОГЭ и ЕГЭ. Открываются по ссылке в браузере, их можно и скачать одним файлом.
  Во многих играх есть контрольная на 10 минут с оценкой».
- **Меню сообщества**: 7 класс · 8 класс · 9 класс / ОГЭ · Все игры — ссылки на каталог сайта
  с фильтром (`/catalog/?grade=8`).
- **Закреплённый пост-навигатор**: что здесь есть, как запустить игру на уроке (ссылка `infoshag.ru/igra/<slug>/`),
  оглавление по классам со ссылками на сайт. Обновлять при каждой новой игре.

## Шаблон поста об игре

```
🎮 <Название> — <тема>, <класс> класс

<1–2 предложения: что делает ученик и чем это полезно>

✅ <главная фишка, например: «каждая ошибка объясняется по шагам»>
📝 Есть контрольная на 10 минут с критериями и оценкой
📱 Работает на доске, компьютере и телефоне — без установки

▶ Играть: <ссылка на /item/<slug>/>

#информатика_<класс>класс #<тема> #ОГЭ_информатика
```

К посту — клип с геймплеем или 2–3 скриншота. Хэштеги держать одной системой, чтобы по клику находились все посты темы.

## Клипы

Короткие ролики с процессом игры — главный двигатель роста (так растёт и сообщество-ориентир).

- Длина 15–30 с. Первые 2 секунды — самое зрелищное: ответ, анимация, «Верно!».
- Запись экрана в OBS (пошаговая настройка — `docs/OBS.md`), без курсора-«бегуна»: движения спокойные.
- Вертикальная версия для клипов: игра в центре, сверху крупная подпись темы, снизу — призыв «ссылка в профиле».
- Тот же исходник после сжатия идёт на стену сайта (`docs/SITE.md`, раздел «Ролики»).

**Сценарии для готовых игр** (по одному клипу на игру):

| Игра | Что показать |
|---|---|
| Охота за расширениями | серия попаданий до ×5, появляется акула и съедает пузырь |
| Звёздная почта | ловушка: длинное послание оказывается легче короткого |
| Зажги число | число 37 — лампочки зажигаются одна за другой, сумма сходится |
| Числовые весы | 21₈ против 21₁₆: весы качаются, появляются 17 и 33 |
| Двоичный столбик | сложение с переносами, «пишем 0, единицу переносим» |
| Истинно / Ложно | цветной кусок формулы ↔ его столбец таблицы заполняются по очереди |
| Поисковые круги | ошибка → разбор по шагам подсвечивает области на кругах |
| Верю — не верю | «range(1, 5) выполнится 5 раз» → «Верю» → трассировка: i = 1, 2, 3, 4 — и стоп |

## Ритм и рост

- 3–4 публикации в неделю: клип, пост о новой игре, «как использовать на уроке», разбор задания ОГЭ.
- Новую игру анонсировать постом + клипом в день выхода.
- Звать учителей: коллеги, методические объединения, учительские сообщества и чаты — только там,
  где правила разрешают делиться материалами.
- Спрашивать в постах, какую тему сделать следующей: отклики → банк идей (`docs/GAMES.md`).
