# Разбор задания 5

Актуальный источник — `games-src/ege-5/template.html`, основанный на доработанном HTML автора из Downloads. Он сохраняет 16 блоков Python, шесть типов вопросов, троичную версию, три тренировочные задачи и оформление.

Основное решение: список a, цикл по n от 1 до 999, построение b, условие n % 3, получение r, отбор r > 150 и min(a). Своя функция используется только для одного действия — перевода системы счисления. Остатки добавляются справа; результат разворачивается через s[::-1].

После правки шаблона:

```sh
node scripts/build-ege5-guide.mjs
npm run validate
```

Готовый самодостаточный файл — `public/games/ege-5-poshagovo.html`.
`GUIDE-DRAFT.md` — архивный первоначальный конспект, он больше не участвует в сборке.

Проверено: 16 блоков, 11 строк трассировки, 18 сочетаний типа вопроса и порога, три решения тренировок, 999 входов двоичного алгоритма в сравнении с Python и арифметикой. Функция перевода проверена для 9000 сочетаний числа и основания.

Основной ответ: R = 157 при N = 19. Первое подходящее N = 11 даёт R = 186. Троичный вариант: R = 162.
В анимации перебираются все N от 1 до 999, как в основной программе. В разделе границ отдельно объяснено, почему достаточно даже N от 1 до 46.
