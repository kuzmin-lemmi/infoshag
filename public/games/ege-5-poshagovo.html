02 · самостоятельный пример
Как получить минимальное R?
Теперь используем знакомые блоки вместе. Это учебная задача с собственным сочетанием правил, а не копия демоверсии.
Условие
На вход подаётся натуральное число N ≥ 4.
  1. Строится двоичная запись N без ведущих нулей.
  2. Подсчитываются единицы в исходной записи.
  3. Если единиц чётное количество, справа дописываются две последние цифры исходной записи.
  4. Если единиц нечётное количество, слева дописывается 10, а справа — двоичная запись остатка N % 4. Нулевой остаток записывается одной цифрой 0.
  5. Полученная запись — двоичная запись числа R.
Найди минимальное R, превышающее 230. Ответ запиши в десятичной системе.
Ищем минимум результата R. Минимальный подходящий вход N — другой вопрос.

04 · перед перебором
Почему достаточно проверить до 240?
Сначала найдём подходящий результат
Для N = 60 запись равна 111100. Единиц четыре, поэтому приписываем последние две цифры 00.
111100 + 00 = 11110000₂ = 240
Число 240 превышает 230. Значит, минимальный подходящий результат уже не больше 240.
Теперь исключим лишние входы
В обеих ветвях к записи N только добавляются цифры. Поэтому R ≥ N.
При N > 240 получится R > 240. Такой результат не улучшит уже найденный. Проверим все N от 4 до 240 включительно:
for n in range(4, 241):
Эта граница выведена для нашего алгоритма. В другой задаче её нужно обосновать заново.

06 · полное решение
Вся программа на Python
Сначала обычный цикл, затем компактная запись. Скопируй программу и проверь её в Python.
Тот же поиск одной строкой
answer = min(r for n in range(4, 241) if (r := transform(n)) > 230)
:= сохраняет результат в r. Функция вызывается один раз на каждый N. Эта запись заменяет только цикл поиска, а сама функция transform всё равно нужна.
Как узнать не только R, но и исходное N?
pairs = []
for n in range(4, 241):
    r = transform(n)
    if r > 230:
        pairs.append((r, n))
print(min(pairs))
Пара (r, n) сравнивается сначала по R. Если поменять элементы местами, будем искать минимум N.

08 · когда освоен основной маршрут
Приёмы для других вариантов
Троичная запись, сумма цифр, инверсия, замена разрядов и другие операции. Возвращайся к нужному приёму по условию своей задачи.
Другие системы счисления
oct(n)[2:]             # восьмеричная запись
hex(n)[2:]             # шестнадцатеричная запись, буквы a–f
format(n, 'X')         # шестнадцатеричная запись с буквами A–F
int('102', 3)          # из троичной записи в число: 11
int('AF', 16)          # из шестнадцатеричной: 175


bin(n) не превращается в троичную функцию от замены среза. Для перевода неотрицательного целого в основание от 2 до 10 можно написать отдельную функцию:


def to_base(n, base):
    if n == 0:
        return '0'
    digits = ''
    while n > 0:
        digits = str(n % base) + digits
        n //= base
    return digits


Здесь сначала получаем младшую цифру через %, поэтому добавляем её слева. // — целочисленное деление. Для оснований выше 10 потребуется алфавит цифр, а не str остатка.


Сумма цифр
s = '1202'
digit_sum = sum(int(digit) for digit in s)  # 5
# То же короче:
digit_sum = sum(map(int, s))


map(int, s) превращает каждый символ в целое число, sum складывает их. Эта запись подходит для цифр 0–9. Для шестнадцатеричных букв нужна явная система: sum(int(digit, 16) for digit in s).


Повторное дописывание контрольного бита
for _ in range(2):
    b += str(b.count('1') % 2)


На каждой итерации подсчитываются единицы в текущей строке. Это отличается от однократного вычисления остатка и повторения одной и той же цифры два раза.


Замена части записи
b = '10' + b[2:]       # заменить первые два разряда
b = b[:-2] + '01'      # заменить последние два разряда


Замена удаляет прежние символы, дописывание сохраняет их. Условия длины и пустой строки проверяем по условию конкретной задачи.


Инверсия и разворот
inverted = ''.join('1' if digit == '0' else '0' for digit in b)
reversed_bits = b[::-1]


Инверсия меняет значения цифр, разворот — их порядок. Для b = '1100' получаем соответственно '0011' и '0011', но это случайное совпадение; для '1101' результаты уже '0010' и '1011'.


Нельзя инвертировать через b.replace('0', '1').replace('1', '0'): второй вызов заменит и только что созданные единицы. Альтернатива без этой ошибки:


inverted = b.translate(str.maketrans('01', '10'))


Фиксированная разрядность
b = format(n, '08b')  # для n = 5 получим '00000101'
# Или:
b = bin(n)[2:].zfill(8)


Дополняем нулями только когда этого требует условие. Ширина здесь минимальная: слишком большое число не обрежется до восьми разрядов. Для восьмиразрядной записи нужно отдельно ограничить входные значения диапазоном 0–255.


Сортировка сумм десятичных цифр
s = str(n)
a, b, c, d = map(int, s)  # если n точно четырёхзначное
sums = [a + b, b + c, c + d]
sums = sorted(sums)
result = int(''.join(map(str, sums[1:])))


Сортируем числа до преобразования в строки: число 12 больше 3, а строка '12' при лексикографическом сравнении меньше '3'. Срез [1:] удаляет одну минимальную сумму, даже если таких сумм несколько.


Арифметические эквиваленты для проверки
Для двоичной записи неотрицательного числа:


n * 2       # дописать 0 справа
n * 2 + 1   # дописать 1 справа
n // 2      # удалить последнюю двоичную цифру
n % 4       # числовое значение последних двух разрядов


Приписать двоичный фрагмент длиной k со значением t означает получить n * 2**k + t. Длина важна: фрагменты '1' и '01' имеют одно числовое значение, но приписывание даёт разные результаты.


Побитовые сдвиги << и >>, а также n.bit_count() можно показать как дополнительные эквиваленты после освоения строкового решения. Они не требуются для основной программы.
