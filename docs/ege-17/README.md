# Разбор задания 17

Готовый самодостаточный файл — `public/games/ege-17-poshagovo.html`. Обложка сайта — `public/posts/ege-17-poshagovo.jpg`, 1280×800 (16:10), подготовлена через image_gen; описание композиции сохранено в `design/site/ege-17-poshagovo-prompt.txt`.

Материал для показа учителем: 15 приёмов Python, 30 карточек для тетради, код и демонстрация рядом, объяснение в отдельном синхронизированном окне. Блок решения задачи всегда расположен сразу под блоком приёмов. Его девять шагов переключаются независимо от выбранного приёма. Настройка текста — 22–32 px, по умолчанию 24 px; доступны полноэкранный режим и клавиатура.

Учебная задача использует минимальный положительный элемент, кратный 7. В соседней паре требуется ровно один отрицательный элемент и делимость модуля разности на найденный порог. Встроенные данные составлены самостоятельно, условие изменено; это не официальная демоверсия. Для 13 чисел порог равен 7, подходят 7 пар, максимальная сумма равна 21. Итоговая программа и текстовый файл скачиваются из HTML.

Проверки: `npm run validate`; автоматический перебор всех приёмов и этапов решения в браузере, проверка всех 12 пар и ответа `7 21`; запуск скачанной программы на Python. Отдельно проверяются постоянное размещение обоих блоков, код рядом с результатом, окно объяснения, переходы и отсутствие горизонтального переполнения на 1366, 1024 и 390 px.
