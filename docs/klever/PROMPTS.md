# Готовые запросы для Claude Code

Копируй по одному в начале сессии. Для крупных этапов сначала включай режим планирования
(Shift+Tab → Plan mode), проверь план и только потом разрешай выполнение.

## Этап 0
```
Прочитай AGENTS.md, docs/klever/WORLD.md и docs/klever/PLAN.md.
Выполни этап 0 из PLAN.md: каркас сборки (scripts/build-game.mjs, games-src/klever/template.html,
скрипты в package.json) и статичный макет экрана со всей графикой из SVG.
Логику не пиши. В конце собери public/games/klever.html и опиши, что посмотреть.
```

## Этап 1
```
Прочитай AGENTS.md и docs/klever/PLAN.md. Выполни этап 1 «Ядро».
Начни с world.js и тестов к нему, потом program.js и interpreter.js с тестами,
потом render.js и editor.js. Сделай 5 уровней главы 1 по WORLD.md.
Прогони npm test и npm run game:klever, сделай коммит.
```

## Этап 2
```
Прочитай AGENTS.md и docs/klever/PLAN.md. Выполни этап 2 «Циклы и проверка на вариантах».
Особое внимание — checker.js и общему тесту levels.test.mjs: каждое неверное решение
из wrongSolutions должно проваливаться хотя бы на одном варианте.
Сделай главы 2 и 3 по 5 уровней. Тесты, сборка, коммит.
```

## Этап 3
```
Прочитай AGENTS.md и docs/klever/PLAN.md. Выполни этап 3 «Ветвление и вспомогательные алгоритмы».
Главы 4 и 5 по 5 уровней. Тесты на воду и рекурсию. Сборка, коммит.
```

## Этап 4
```
Прочитай AGENTS.md и docs/klever/PLAN.md. Выполни этап 4 «КуМир».
Сначала дерево → текст и вкладка «Текст», потом разбор текста с сообщениями об ошибках
по-русски и с номером строки. Глава 6 в формате ОГЭ. Тесты туда-обратно для всех эталонов.
```

## Этап 5
```
Прочитай AGENTS.md и docs/klever/PLAN.md. Выполни этап 5: звёзды, карта станции,
сохранение прогресса и контрольная на 10 минут строго по стандарту из AGENTS.md.
```

## Этап 6
```
Прочитай AGENTS.md и docs/klever/PLAN.md. Выполни этап 6: редактор уровней для учителя
и открытие уровня по ссылке. Тест: уровень → ссылка → уровень без потерь.
```

## Этап 7
```
Прочитай AGENTS.md и docs/klever/PLAN.md. Выполни этап 7: полировка, звук, финальная сцена,
карточка src/content/items/klever.md. Пройди чек-лист из AGENTS.md и собери сайт.
```
