Программа разобрана по блокам: чтение файла, расстояние между звёздами, сбор кластеров, поиск центра, ответ. Каждую строку кода можно нажать — справа появится, что она делает, с примерами значений и записью «то же самое длинно». Рядом с каждым блоком — живой пример на файле А: как строка файла превращается в пару чисел, расстояние между двумя выбранными звёздами, пошаговый показ сбора кластера с очередью звёзд, поиск центра по сумме расстояний.

Типичные ошибки показаны наглядно: `clusters[-1] = clusters[-1] + n` вместо `+=` разваливает кластеры на куски, ползунок порога показывает, почему он именно 1, а таблица «int или round» — почему ответ нельзя округлять. После каждого шага — вопросы «Проверь себя» с объяснением каждого неверного ответа.

Отдельный шаг показывает, что та же программа без правок решает файл Б с тремя кластерами; ответ для Б спрятан, чтобы ученик сначала запустил программу сам. Файлы А и Б можно скачать, а на странице — проверить ответ на любом своём файле с данными. Данные файлов составлены для этого разбора.
