# «Снайпер» — план разработки

Тренажёр задания 3 ОГЭ по информатике: найти наименьшее (наибольшее) целое число x, при котором
логическое высказывание истинно (ложно). Ученик «стреляет» по точке числовой прямой; при промахе
прямая раскладывает условие на части и показывает, где ошибка.

| | |
|---|---|
| Файл | `public/games/snaiper.html` — один самодостаточный HTML, < 1500 строк (модули не нужны) |
| Карточка | `src/content/items/snaiper.md`, `type: trainer`, `grades: [8, 9]`, `order: 35` |
| Тема | «Логические выражения с числами: задание 3 ОГЭ» |
| Учебник | Босова, 8 класс — элементы алгебры логики |
| Срок | 3–5 рабочих дней; выпустить до контрольной по логике (≈ 20–27 ноября) |
| Стандарт | `AGENTS.md`, раздел 5: стартовый экран, тренировка, контрольная на 10 минут, разбор каждой ошибки |

---

## 1. Что именно тренируем

**Формат задания ОГЭ** (сверить с демоверсией ФИПИ текущего года на этапе 0):

> Напишите наименьшее целое число x, для которого истинно высказывание:
> НЕ (X < 5) И (X < 9).

Варианты формулировки, которые встречаются в банке ФИПИ и сборниках:
- наименьшее / наибольшее;
- истинно / **ложно**;
- целое / натуральное / двузначное / трёхзначное;
- части условия: сравнения (`<`, `>`, `<=`, `>=`), «x чётное / нечётное», «x делится на k»,
  «последняя цифра x равна d», «первая цифра x чётная»;
- реже: «сколько существует натуральных x…» (уровень для сильных).

**Типичные ошибки — из них строим ловушки и разбор**

| Код | Ошибка | Пример |
|---|---|---|
| `neg-strict` | НЕ меняет знак, но не строгость: `НЕ (x < 5)` → `x > 5` | ответ 6 вместо 5 |
| `strict` | Путают строгое и нестрогое неравенство на границе | `x > 5` → ответ 5 |
| `no-not` | Не замечают НЕ | считают `x < 5` |
| `and-or` | Читают И как ИЛИ (объединение вместо пересечения) или наоборот | |
| `false` | Не заметили «ложно» — ищут, где истинно | |
| `min-max` | Перепутали наименьшее и наибольшее | |
| `domain` | Забыли ограничение «двузначное / натуральное» | ответ 7 для двузначного |
| `part` | Учли только одну часть условия | |

Генератор для каждого задания заранее считает ответы «с ошибкой» каждого вида. Если ответ ученика
совпал с одним из них — разбор начинается с названия ошибки: «Похоже, ты решил, что НЕ (x < 5) — это
x > 5. На самом деле НЕ (x < 5) — это x ≥ 5, и 5 тоже подходит».

## 2. Игровой процесс

**Экран задания**
- Сверху — условие крупно, каждая часть своим цветом (как в «Истинно / Ложно»): `НЕ (X < 5)` розовая,
  `(X < 9)` голубая; операции И / ИЛИ / НЕ выделены.
- Под ним — числовая прямая с целыми точками в окне 20–40 чисел (окно выбирается так, чтобы ответ
  и ловушки были внутри, а не на краю). Для двузначных и трёхзначных чисел — прямая с прокруткой
  и масштабом, плюс поле ввода числа.
- Прицел двигается мышью / касанием / стрелками; клик или Enter — выстрел. Можно ввести число с клавиатуры.

**Попадание** — точка вспыхивает, очки, серия растёт. Затем короткая проверка: прямая на секунду
показывает цветные полосы частей и их пересечение — закрепление, а не только «верно».

**Промах** — разбор по шагам (кнопка «Дальше» или автоматически):
1. Подстановка выбранного x в каждую часть: `НЕ (6 < 5) = НЕ (ложь) = истина`, `6 < 9 = истина`,
   `истина И истина = истина` — «твоё число подходит, но оно не наименьшее» или «не подходит, потому что…».
2. Каждая часть превращается в полосу на прямой: `НЕ (X < 5)` → `X ≥ 5`.
3. Полосы складываются по операции: И — пересечение, ИЛИ — объединение; «ложно» — дополнение.
4. Подсвечивается крайняя точка — правильный ответ; рядом подпись «граница входит / не входит».
5. Если ответ совпал с ловушкой — название ошибки и правило из справки.

## 3. Режимы

**🎯 Тренировка** — настройки: уровень (или «по порядку»), формулировки (только «истинно» / с «ложно»),
тип чисел. Очки, серия и множитель до ×5, рекорд в `localStorage` (в `try/catch`).

**Уровни**

| № | Название | Что в условии | Пример |
|---|---|---|---|
| 1 | Разминка | одно сравнение | `X > 7`, наименьшее целое |
| 2 | Отрицание | `НЕ` + одно сравнение | `НЕ (X <= 3)` |
| 3 | Отрезок | И из двух сравнений, одно под НЕ | `НЕ (X < 5) И (X < 9)` |
| 4 | Или | ИЛИ, наибольшее / наименьшее с разрывом | `(X < 4) ИЛИ НЕ (X < 10)` при ограничении |
| 5 | Свойства числа | сравнение + чётность / делимость / последняя цифра | `НЕ (X < 20) И (X чётное)` |
| 6 | Ложно | те же условия, вопрос «ложно» | |
| 7 | Цифры | двузначные / трёхзначные, «первая цифра» | наименьшее трёхзначное, `(первая цифра чётная) И НЕ (X < 230)` |
| 8 | Сколько | количество x на отрезке | для сильных, в контрольную не входит |

Уровни 1–2 — подготовительные (в ОГЭ так просто не бывает), 3–7 — формат ОГЭ.

**🔎 Отметь все** (дополнительный, короткий) — на прямой из 15–20 точек отметить все x, где условие
истинно. Учит видеть множество, а не угадывать одну точку. Хорош для объяснения у доски.

**📝 Контрольная на оценку** — по стандарту `AGENTS.md`:

```js
const EXAM = {
  minutes: 10,
  seq: [3, 3, 4, 5, 3, 6, 4, 5, 7, 6, 5, 7],      // уровни заданий по порядку, дальше по кругу
  points: { 3: 1, 4: 2, 5: 2, 6: 2, 7: 3 },
  errorPenalty: 0,                                 // промах просто не приносит баллов
  grades: [[14, 5], [10, 4], [6, 3], [0, 2]]       // пороги проверить на уроке
};
```

Одна попытка на задание, разбор — на экране результата (во время контрольной только «принято»).
Поле «Фамилия и имя», 10 минут по `Date.now()`, счёт уходов со страницы (`visibilitychange`),
результат с оценкой, датой, разбивкой по уровням и блоком «Над чем поработать» по кодам ошибок.

**📖 Справка** (в контрольной закрыта): как снимать НЕ (`<` ↔ `>=`, `>` ↔ `<=`), И — пересечение,
ИЛИ — объединение, порядок НЕ → И → ИЛИ, «ложно» = ищем, где НЕ (условие) истинно,
алгоритм решения задания 3 по шагам с примером.

## 4. Генератор заданий

```
genTask(level) → { atoms, expr, ask: {extreme: 'min'|'max', want: true|false},
                   domain: {lo, hi, label}, answer, traps: {code: value}, window: [a, b] }
```

- **Атомы**: `cmp(op, c)` — сравнение; `even`, `odd`, `div(k)`, `last(d)`, `firstEven` и т. п.
- **Ответ** — перебором по области (`domain`): целые −50…150, натуральные 1…150, двузначные 10…99,
  трёхзначные 100…999. Перебор надёжнее формул и сразу даёт ответы-ловушки.
- **Ловушки** — тот же перебор по изменённому выражению: снять строгость под НЕ, выбросить НЕ,
  заменить И↔ИЛИ, перевернуть «ложно», min↔max, без ограничения области, одна часть вместо двух.
- **Отбраковка** (повторить генерацию, если):
  - решения нет или ответ — край области, когда условие на край не влияет (неограниченное «наименьшее целое»);
  - ответ виден без вычислений (одна часть условия ничего не меняет);
  - все ловушки совпадают с ответом (задание не проверяет понимание);
  - числа выходят за окно прямой.
- Повторы: не выдавать одинаковый шаблон два раза подряд.

## 5. Внешний вид

- Тема — тир на полигоне: тёмно-зелёная / песочная палитра, прицел, мишени-точки. Свой мир, без
  узнаваемых образов из игр и фильмов.
- Крупные цифры для проектора, высокий контраст; светлая и тёмная тема через `prefers-color-scheme`.
- Анимации: выстрел, вспышка точки, разворачивание полос при разборе; `prefers-reduced-motion` — без них.
- Клип для ВК (15–30 с): промах по 6 → прямая раскладывается на полосы → `НЕ (X < 5)` становится
  `X ≥ 5` → выстрел в 5, попадание.
