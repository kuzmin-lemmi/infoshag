## Часть 1 Небольшие блоки Python

Каждый блок будущей страницы: короткое объяснение → запускаемый пример → изменение входного значения → вопрос с разбором ошибки. Приёмы идут в том порядке, в котором понадобятся в программе.

### 1 Число и его запись

```python
n = 13
b = '1101'
```

`n` — целое число. `b` — строка из символов. Строку удобно разрезать, дополнять и читать по символам. Считать с ней как с целым числом нельзя: `'13' + '2'` даёт `'132'`, а `13 + 2` — `15`.

В разборе используем три разных имени: `n` — исходное число, `b` — его двоичная запись, `r` — числовой результат алгоритма.

### 2 Перевод в двоичную запись

```python
n = 13
print(bin(n))       # 0b1101
b = bin(n)[2:]
print(b)            # 1101
```

`bin` возвращает строку. Первые два символа `0b` обозначают основание системы счисления. Срез `[2:]` берёт символы начиная с индекса 2 до конца. Индексы начинаются с нуля.

`bin(n)[2:]` подходит для неотрицательных чисел. Для отрицательного числа запись начинается с `-0b`; в нашей задаче таких входных данных нет. Для нуля получится `'0'`, а не пустая строка.

Альтернативный однострочник:

```python
b = format(n, 'b')   # сразу '1101', без 0b
```

В основном решении оставим один способ — `bin(n)[2:]`, чтобы не менять запись от шага к шагу.

### 3 Чтение отдельных цифр и срезов

```python
b = '1101'
print(b[0])     # 1 — первый символ
print(b[-1])    # 1 — последний символ
print(b[:2])    # 11 — первые два
print(b[-2:])   # 01 — последние два
print(b[2:])    # 01 — всё после первых двух
print(b[:-2])   # 11 — всё, кроме последних двух
print(len(b))   # 4 — длина записи
```

В срезе `[начало:конец]` конец не включается. У `[-2:]` нет правой границы: это два последних символа до конца строки.

Если строка короче двух символов, `b[-2:]` вернёт всю строку без ошибки. Удаление последних двух символов из короткой строки может дать `''`; `int('', 2)` уже вызовет ошибку. В основной задаче `n ≥ 4`, поэтому исходная двоичная запись содержит хотя бы три цифры.

### 4 Подсчёт единиц

```python
b = '1101'
ones = b.count('1')
print(ones)          # 3
```

`count` — метод строки. Ему передаём символ `'1'` в кавычках. `b.count(1)` неверно: аргумент должен быть строкой.

В двоичной записи сумма цифр равна количеству единиц. Для троичной записи это уже не так: у `'102'` одна единица, а сумма цифр равна 3.

### 5 Остаток и чётность

```python
print(13 % 4)             # 1
print(14 % 4)             # 2
print(b.count('1') % 2)   # 1
```

`%` вычисляет остаток от деления. Чётное число даёт остаток 0 при делении на 2, нечётное — 1.

```python
n % 2 == 0               # исходное число чётное?
b.count('1') % 2 == 0    # количество единиц чётное?
```

Это разные вопросы. Например, `n = 6` — чётное число, а его запись `'110'` содержит две единицы. У `n = 8` тоже чётное значение, но единица в записи `'1000'` только одна.

`=` присваивает значение; `==` сравнивает значения.

### 6 Дописывание символов

```python
b = '1101'
print(b + '00')       # 110100 — дописали справа
print('10' + b)       # 101101 — дописали слева
print('10' + b + '0') # 1011010 — с двух сторон
```

Строки соединяются слева направо. Никакого сложения чисел здесь нет. Строка неизменяема: выражение `b + '00'` само по себе не меняет `b`. Нужно сохранить результат:

```python
b = b + '00'
# То же самое короче:
b += '00'
```

Если дописываем числовой остаток как одну цифру, нужен `str`:

```python
b += str(b.count('1') % 2)
```

Если нужно дописать двоичную запись числа, используем `bin`, а не `str`:

```python
print(str(3))       # 3
print(bin(3)[2:])   # 11
```

### 7 Сохранение исходной записи

```python
b = '1101'
tail = b[-2:]
result_bits = b + tail
print(result_bits)   # 110101
```

Сначала извлекаем нужный фрагмент исходной записи, затем строим новую. Это помогает не перепутать, к какой версии строки относится правило.

Если в условии сказано повторить действие над уже полученной записью, значения, наоборот, нужно пересчитывать после каждого изменения. Исходная запись и текущая запись — не одно и то же.

### 8 Выбор одной из двух ветвей

```python
if b.count('1') % 2 == 0:
    result_bits = b + b[-2:]
else:
    remainder_bits = bin(n % 4)[2:]
    result_bits = '10' + b + remainder_bits
```

Выполняется ровно одна ветвь. Двоеточие начинает блок; строки блока имеют одинаковый отступ. Два независимых `if` могут дать другое поведение, если первый блок изменил данные для второго условия.

Тернарная запись существует, но показываем её только после развёрнутого варианта:

```python
result_bits = b + b[-2:] if b.count('1') % 2 == 0 else '10' + b + bin(n % 4)[2:]
```

Она не является обязательной целью: в длинном выражении сложнее заметить неправильную переменную или порядок действий.

### 9 Перевод результата в число

```python
print(int('110101', 2))  # 53
print(int('110101'))     # 110101 — это другое число
```

Второй аргумент `2` означает, что входная строка записана в двоичной системе. Получаем обычный объект `int`, который можно сравнивать с десятичным порогом.

Нули внутри фрагментов нельзя терять: `'1101' + '01'` даёт `'110101'`. Превращение `'01'` в целое число до соединения уничтожит начальный ноль фрагмента.

### 10 Функция для одного входного числа

```python
def transform(n):
    b = bin(n)[2:]
    if b.count('1') % 2 == 0:
        result_bits = b + b[-2:]
    else:
        remainder_bits = bin(n % 4)[2:]
        result_bits = '10' + b + remainder_bits
    return int(result_bits, 2)
```

Функция принимает одно `n`, выполняет алгоритм и возвращает одно `r`. `return` нужен, чтобы использовать результат при поиске. `print` только выводит его на экран и не заменяет `return`.

### 11 Перебор входных значений

```python
for n in range(4, 10):
    r = transform(n)
    print(n, r)
```

Перебираются 4, 5, 6, 7, 8, 9. Правая граница `range` не включается. Чтобы проверить все числа от 4 до 240 включительно, нужно `range(4, 241)`.

### 12 Отбор и поиск минимума

```python
results = []
for n in range(4, 241):
    r = transform(n)
    if r > 230:
        results.append(r)
print(min(results))
```

`append` добавляет один результат в список. `min` выбирает наименьший. Для пустого списка `min` без дополнительного аргумента вызовет ошибку; в нашей задаче наличие подходящего значения докажем заранее.

После понятного цикла можно показать компактную запись:

```python
answer = min(r for n in range(4, 241) if (r := transform(n)) > 230)
```

`:=` вычисляет значение и одновременно сохраняет его в `r`. Это дополнительный приём, а не обязательная часть решения. Его преимущество здесь — функция вызывается один раз на каждое `n`.

## Часть 2 Самостоятельная задача средней сложности

### Условие

Алгоритм получает натуральное число N, не меньшее 4, и строит число R.

1. Записывает N в двоичной системе без ведущих нулей.
2. Подсчитывает единицы в этой исходной записи.
3. Если количество единиц чётное, приписывает справа две последние цифры исходной записи.
4. Если количество единиц нечётное, приписывает слева `10`, а справа — двоичную запись остатка от деления N на 4. Нулевой остаток записывается одной цифрой `0`; остальные остатки тоже записываются без дополнительных ведущих нулей.
5. Полученную запись рассматривает как двоичную запись числа R.

Найди минимальное значение R, превышающее 230. Ответ запиши в десятичной системе.

Примеры: для N = 13 получается R = 91, для N = 14 — R = 186.

### Шаг 1 Уточняем что требуется найти

Требуется минимальное **R**, а не минимальное N. Условие `R > 230` строгое: само число 230 не подходит.

При переборе N по возрастанию результаты R могут уменьшаться. Например, для N = 7 получаем 95, а для N = 8 — 80. Поэтому `break` при первом подходящем входном числе пока применять нельзя.

### Шаг 2 Проверяем обе ветви вручную

Возьмём N = 13.

| Действие | Значение |
| --- | --- |
| Исходная двоичная запись | `1101` |
| Количество единиц | 3 |
| Ветвь | нечётное количество единиц |
| Остаток N % 4 | 1 |
| Запись остатка | `1` |
| Новая запись | `10` + `1101` + `1` = `1011011` |
| Число R | 91 |

Здесь само N нечётное, но ветвь выбирается по количеству единиц, а не по чётности N.

Теперь N = 6: двоичная запись `110`, две единицы, поэтому срабатывает чётная ветвь. Последние две цифры — `10`; результат `11010`, то есть R = 26.

### Шаг 3 Проверяем остаток из двух цифр

При N = 14 запись равна `1110`, единиц три. Остаток 14 % 4 = 2 записывается как `10`. Получаем `10` + `1110` + `10` = `10111010`, то есть R = 186.

Если написать `str(n % 4)`, в строке появится символ `2`, недопустимый для двоичной записи. Поэтому нужен именно `bin(n % 4)[2:]`.

### Шаг 4 Проверяем нулевой остаток

При N = 4 запись равна `100`, единица одна, остаток равен 0. Его запись — `0`. Получаем `10` + `100` + `0` = `101000`, то есть R = 40.

Здесь нельзя заменять нулевой остаток пустой строкой и нельзя без указания в условии дополнять его до `00`.

### Шаг 5 Собираем функцию

Используем функцию `transform` из первой части. Нажатие строки в интерактивной версии должно показывать её смысл и значения для выбранного N. Первые контрольные входы: 4, 6, 13, 14.

| N | Исходная запись | Единиц | Новая запись | R |
| --- | --- | --- | --- | --- |
| 4 | `100` | 1 | `101000` | 40 |
| 6 | `110` | 2 | `11010` | 26 |
| 13 | `1101` | 3 | `1011011` | 91 |
| 14 | `1110` | 3 | `10111010` | 186 |

### Шаг 6 Обосновываем границы перебора

Здесь не будем угадывать верхнюю границу `1000` или `10000`.

В обеих ветвях к записи положительного N дописываются цифры без удаления исходных разрядов. В чётной ветви R ≥ 4N, в нечётной ветви добавляются цифры слева и хотя бы одна справа, поэтому также R ≥ N.

Проверим N = 60. Его запись `111100` содержит четыре единицы. Приписываем `00`, получаем `11110000`, то есть R = 240. Подходящий результат уже найден, следовательно, минимальный подходящий R не больше 240.

При N > 240 результат R ≥ N > 240, поэтому улучшить найденный результат он не может. Достаточно проверить N от 4 до 240 включительно. Это не универсальная граница для всех задач № 5: она выведена из конкретного алгоритма.

### Шаг 7 Пишем полную программу

```python
def transform(n):
    b = bin(n)[2:]
    if b.count('1') % 2 == 0:
        result_bits = b + b[-2:]
    else:
        remainder_bits = bin(n % 4)[2:]
        result_bits = '10' + b + remainder_bits
    return int(result_bits, 2)


results = []
for n in range(4, 241):
    r = transform(n)
    if r > 230:
        results.append(r)

print(min(results))
```

Вывод: `234`.

### Шаг 8 Проверяем ответ в обратную сторону

Минимум получается при N = 58. Его двоичная запись — `111010`, единиц четыре. Приписываем последние две цифры `10`: `11101010`. Это 128 + 64 + 32 + 8 + 2 = 234. Условие 234 > 230 выполнено.

Первое подходящее N при переборе — 19, и оно даёт R = 335. Если остановиться на нём, получится неправильный ответ. Позже, при N = 58, находится меньший результат.

Пара для проверки результата:

```python
pairs = []
for n in range(4, 241):
    r = transform(n)
    if r > 230:
        pairs.append((r, n))
print(min(pairs))  # (234, 58)
```

Кортежи сравниваются сначала по первому элементу. Поэтому для поиска минимума R используем `(r, n)`, а не `(n, r)`.

### Шаг 9 Проверяем понимание

1. Почему для N = 6 выполняется ветвь с чётным количеством единиц? Ответ: в `110` две единицы; чётность самого N не является условием ветви.
2. Что вернёт `'111010'[-2:]`? Ответ: `'10'`; `[:2]` вернул бы `'11'`.
3. Можно ли записать остаток 2 строкой `'2'`? Ответ: нет, нужна двоичная запись `'10'`.
4. Что получится из `int('101000')` без второго аргумента? Ответ: сто одна тысяча, а не 40.
5. Почему нельзя сразу вывести 335? Ответ: это результат первого подходящего N, а нужен минимум среди R.
6. Почему не перебираем N больше 240? Ответ: найден результат 240, а во всех ветвях R ≥ N; большие N не улучшат ответ.

## Часть 3 Приёмы для других вариантов задания 5

Эта часть открывается после основного решения. Она расширяет библиотеку приёмов из сборника, но не перегружает первый проход по задаче.

### Другие системы счисления

```python
oct(n)[2:]             # восьмеричная запись
hex(n)[2:]             # шестнадцатеричная запись, буквы a–f
format(n, 'X')         # шестнадцатеричная запись с буквами A–F
int('102', 3)          # из троичной записи в число: 11
int('AF', 16)          # из шестнадцатеричной: 175
```

`bin(n)` не превращается в троичную функцию от замены среза. Для перевода неотрицательного целого в основание от 2 до 10 можно написать отдельную функцию:

```python
def to_base(n, base):
    if n == 0:
        return '0'
    digits = ''
    while n > 0:
        digits = str(n % base) + digits
        n //= base
    return digits
```

Здесь сначала получаем младшую цифру через `%`, поэтому добавляем её слева. `//` — целочисленное деление. Для оснований выше 10 потребуется алфавит цифр, а не `str` остатка.

### Сумма цифр

```python
s = '1202'
digit_sum = sum(int(digit) for digit in s)  # 5
# То же короче:
digit_sum = sum(map(int, s))
```

`map(int, s)` превращает каждый символ в целое число, `sum` складывает их. Эта запись подходит для цифр 0–9. Для шестнадцатеричных букв нужна явная система: `sum(int(digit, 16) for digit in s)`.

### Повторное дописывание контрольного бита

```python
for _ in range(2):
    b += str(b.count('1') % 2)
```

На каждой итерации подсчитываются единицы в текущей строке. Это отличается от однократного вычисления остатка и повторения одной и той же цифры два раза.

### Замена части записи

```python
b = '10' + b[2:]       # заменить первые два разряда
b = b[:-2] + '01'      # заменить последние два разряда
```

Замена удаляет прежние символы, дописывание сохраняет их. Условия длины и пустой строки проверяем по условию конкретной задачи.

### Инверсия и разворот

```python
inverted = ''.join('1' if digit == '0' else '0' for digit in b)
reversed_bits = b[::-1]
```

Инверсия меняет значения цифр, разворот — их порядок. Для `b = '1100'` получаем соответственно `'0011'` и `'0011'`, но это случайное совпадение; для `'1101'` результаты уже `'0010'` и `'1011'`.

Нельзя инвертировать через `b.replace('0', '1').replace('1', '0')`: второй вызов заменит и только что созданные единицы. Альтернатива без этой ошибки:

```python
inverted = b.translate(str.maketrans('01', '10'))
```

### Фиксированная разрядность

```python
b = format(n, '08b')  # для n = 5 получим '00000101'
# Или:
b = bin(n)[2:].zfill(8)
```

Дополняем нулями только когда этого требует условие. Ширина здесь минимальная: слишком большое число не обрежется до восьми разрядов. Для восьмиразрядной записи нужно отдельно ограничить входные значения диапазоном 0–255.

### Сортировка сумм десятичных цифр

```python
s = str(n)
a, b, c, d = map(int, s)  # если n точно четырёхзначное
sums = [a + b, b + c, c + d]
sums = sorted(sums)
result = int(''.join(map(str, sums[1:])))
```

Сортируем числа до преобразования в строки: число 12 больше 3, а строка `'12'` при лексикографическом сравнении меньше `'3'`. Срез `[1:]` удаляет одну минимальную сумму, даже если таких сумм несколько.

### Арифметические эквиваленты для проверки

Для двоичной записи неотрицательного числа:

```python
n * 2       # дописать 0 справа
n * 2 + 1   # дописать 1 справа
n // 2      # удалить последнюю двоичную цифру
n % 4       # числовое значение последних двух разрядов
```

Приписать двоичный фрагмент длиной k со значением t означает получить `n * 2**k + t`. Длина важна: фрагменты `'1'` и `'01'` имеют одно числовое значение, но приписывание даёт разные результаты.

Побитовые сдвиги `<<` и `>>`, а также `n.bit_count()` можно показать как дополнительные эквиваленты после освоения строкового решения. Они не требуются для основной программы.
