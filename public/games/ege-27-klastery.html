Задание 27 по шагам

Разберём задачу про скопления звёзд медленно: по одному блоку кода и по одной строке. Каждую строку можно нажать и прочитать, что она делает. Рядом живой пример на файле А.

Условие · по мотивам задания 27 ЕГЭ

Астроном записал в файл координаты звёзд на карте неба: в каждой строке два числа, x и y. Звёзды собраны в кластеры. Каждый кластер целиком помещается в свой квадрат 3 × 3, и эти квадраты не пересекаются.

Центр кластера — та его звезда, у которой сумма расстояний до всех остальных звёзд кластера наименьшая.

Найди центры всех кластеров. Px — среднее арифметическое абсцисс центров, Py — среднее ординат. В ответ запиши два числа: целую часть Px × 10000 и целую часть Py × 10000. В файле А два кластера, в файле Б три.

План решения
  1. Прочитать файл в список точек.
  2. Научиться считать расстояние между звёздами.
  3. Разбить звёзды на кластеры и проверить их размеры.
  4. Найти центр каждого кластера.
  5. Усреднить координаты центров и записать ответ.
  6. Запустить ту же программу на файле Б.
1

Читаем файл

Файл — это текст. Python пока не знает, что там числа. Наша задача — превратить каждую строку в пару чисел [x, y] и сложить все пары в список data.

Что происходит с одной строкой

Выбери номер строки файла и посмотри, как текст по шагам становится числами.

2

Считаем расстояние

Расстояние нужно дважды: чтобы понять, какие звёзды соседи, и чтобы найти центр. Считаем его по теореме Пифагора.

Попробуй: нажми на одну звезду, потом на другую. Пунктиром нарисуются катеты, сплошной линией — гипотенуза.

Выбери первую звезду.

Круг вокруг первой звезды имеет радиус 1. Звёзды внутри круга — её соседи. Это правило понадобится на шаге 3.

3

Собираем кластеры

Правило: две звезды в одном кластере, если между ними меньше 1. Соседи соседей тоже в этом кластере. Берём звезду, ищем её соседей, потом соседей каждого соседа, и так пока новые не кончатся.

Файл А: шаг за шагом

Каждое нажатие — один проход цикла for. Внизу виден сам список кластера: тёмная клетка — звезда p1, которую проверяем сейчас, красные — только что дописанные соседи. Клавиши: ← →, пробел — авто, Esc — пауза.

Ловушка: += и = … +

Для списков это разные операции. Переключи и посмотри, что станет с кластерами.

Почему порог именно 1

Двигай ползунок и смотри, сколько получится кластеров.

Маленький порог рвёт группы на куски, слишком большой склеивает их. Правильный даёт ровно столько кластеров, сколько сказано в условии.

4

Ищем центр каждого кластера

Для каждой звезды кластера считаем сумму расстояний до всех звёзд кластера. Где сумма меньше всего, там центр. Представь деревню: в каком доме открыть магазин, чтобы все жители вместе прошли как можно меньше?

Пример на 4 звёздах

Кластер [[0, 0], [1, 0], [3, 0], [1, 1]]. На диагонали нули: это расстояние звезды до самой себя.

кандидат pдо (0, 0)до (1, 0)до (3, 0)до (1, 1)сумма s
(0, 0)0131,4145,414
(1, 0)10214,000 ← минимум
(3, 0)3202,2367,236
(1, 1)1,41412,23604,650

min(m) найдёт пару [4.0, [1, 0]], а [1] достанет из неё звезду [1, 0]. Среднее координат здесь (1,25; 0,25), и такой звезды в кластере нет.

Центры на файле А

Нажми на любую звезду выбранного кластера: линии покажут все расстояния, которые складываются в её сумму.

местострока файласумма расстояний
центр ✕ среднее координат — не центр

Частая ошибка: посчитать среднее координат и назвать его центром. Такая точка обычно не совпадает ни с одной звездой, а по условию центр обязан быть звездой кластера.

    Другой способ: рекурсия
    

      

      
Здесь кластер собирает функция, которая вызывает сама себя: каждый найденный сосед ищет своих соседей. sum(next_cluster, []) склеивает список списков в один список. Ответ тот же. Минус: Python разрешает не больше 1000 вложенных вызовов, на длинной цепочке соседей программа упадёт с RecursionError. У способа с циклом из шага 3 такой проблемы нет.
