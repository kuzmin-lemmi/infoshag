ИНФОШАГ · ЗАДАНИЕ 8 ЕГЭ · PYTHON ПО ШАГАМ

Откройте ege-8-poshagovo.html в современном браузере. Интернет и установка Python для демонстрации не нужны. Для запуска скачанных .py-программ нужен Python 3.10 или новее.

На странице три блока методов и шесть авторских задач:
1. Приёмы Python → задачи 1–3: ограничения на слова, перестановки, первый и последний номер.
2. Нумерация и системы счисления → задачи 4–5: слово по номеру, номер слова и числа с ограничениями на цифры.
3. Ускорение подсчёта → задача 6: формула, выбор позиций, рекурсия, отсечения, динамика.

Разделы расположены друг под другом. Для перехода используйте верхнее меню разделов. Метод, задача и шаг выбираются внутри своего блока.

Для проектора: стандартный текст 24 px, кнопки A− / A+ меняют размер от 22 до 32 px. Кнопка «Во весь экран» скрывает панели браузера. Длинный код и таблицы прокручиваются внутри своих областей. Можно переключить светлую и тёмную тему.

Код и результат показаны рядом. «Объяснение в окне» открывает отдельное синхронизированное окно: разрешите всплывающие окна, если браузер его заблокировал. Окно можно перенести на экран учителя.

В первом блоке стрелки ← / → переключают приёмы, клавиши 1 / 2 — объяснение и демонстрацию. В следующих блоках стрелки переключают методы или шаги решения. Page Up / Page Down управляют строками или шагами видимого раздела. Во время ввода параметры меняются обычным способом; клавиши навигации не перехватываются. Escape останавливает автопоказ первого блока.

В пошаговом переборе сначала предложите классу проверить вариант, затем откройте проверку. Итоговый ответ раскрывается отдельной кнопкой. На последнем шаге доступны вся программа, альтернативный способ, копирование и скачивание .py.

В настройках методов можно менять исходные данные. Счётчики относятся ко всему допустимому набору, даже если таблица разбита на страницы. Слишком большой полный перебор не запускается. В задаче 6 длина 5 служит для сравнения методов, длина 18 — для показа ускорения.

Браузерная демонстрация использует встроенную модель алгоритма. Показанные программы проверены запуском в Python; произвольный Python в браузере не исполняется.

Все условия и данные составлены для материала. Это учебные разборы, не копия официальной демоверсии.
