Программа разобрана по блокам: чтение файла и энергия частицы, раскладка по кластерам через `if / elif / else`, функция поиска центра, перебор пар через `itertools.combinations`, расчёт Q1 и Q2. Каждую строку кода можно нажать — справа появится, что она делает, с примерами значений из файла и записью «то же самое длинно».

Рядом с каждым блоком — живой пример. Конвейер показывает, как строка файла превращается в числа и энергию. Ползунки границ показывают, почему подходит любое число из промежутка между группами и что ломается, если граница разрезала группу. График сумм для центра похож на букву V: видно, что центр — частица со средней по порядку энергией. Пары разобраны на четырёх точках, ближайшие частицы IV — на карте каждого кластера. Ловушки: старт минимума с `q1 = 0`, `int` и `round`, среднее по всем частицам вместо среднего по центрам. После каждого шага — вопросы «Проверь себя» с объяснением каждого неверного ответа.

В конце — вся программа с копированием, файл данных для скачивания и проверка на своём файле: страница сама находит промежутки между кластерами; признак и вид величин Q1 и Q2 можно выбрать. Условие по мотивам задания 27 проекта демоверсии 2027: вопросы изменены (Q1 — наименьшее расстояние между частицами IV, Q2 — среднее энергий центров), данные файла составлены для этого разбора.
